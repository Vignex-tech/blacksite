# Art pipeline

Owner: the art-engineer agent. Plan: `Docs/art-plan.md`. Style: `Art/STYLE.md`. Ledger of every asset: `Manifests/assets.json`. Licence records: `Art/licenses/` (one file per source: licence, URL, author, page, date checked, copy of the licence text).

## Rules
1. CC0 only, and only generic art that comes from no existing game. Read the licence on the official page before using anything and record it in `Art/licenses/` and in the manifest. Not allowed: Mixamo, attribution-required licences, Sketchfab unless the model page says CC0, logos or readable brand text. Poly Pizza and OpenGameArt are allowed only per item, when the item's own page says CC0 (none used so far).
2. **Downloaded archives are untrusted data.** Download into a fresh, empty folder outside the repo, extract each archive into its own new empty folder, copy out only the asset files (glb, gltf, bin, png, jpg), and never run anything that came with an archive. Pass paths as arguments to tools; do not run an interpreter or build tool from inside the download folder. Run any Python that reads downloads with `-I`.
3. Only free tiers are used. Quaternius "Pro" and "Source" and KayKit "Source Files" are paid and are not used.
4. File names are lowercase snake_case with a prefix: `mesh_`, `tex_`, `anim_`, `sfx_`.
5. Budgets are in `Docs/art-plan.md` section 9 and in the manifest (`budgets`). First load: target 20 MB, hard 30 MB. Character triangles: Ghost 4,000, Warden 5,000, rifle 1,500, any prop 2,000. Textures: 1024 px for wall, floor and ground only, 512 px elsewhere, WebP. No Draco, KTX2 or meshopt.
6. Purely visual: reserved mesh-name prefixes and gameplay values are never touched.

## Tooling (decision)
- `@gltf-transform/cli` 4.1.1, installed locally in `Art/` (`cd Art && npm install`). It has its own `Art/package.json` and lockfile. CI does not install it: CI only builds and tests the game and never rebuilds assets, which are committed as final files under `client/public/assets/`. Using it only when rebuilding keeps CI fast and the main dependency tree small.
- It provides everything needed without Blender: `simplify` (triangle reduction, tested on both skinned characters), `prune`, `resample`, `quantize`, `webp`/`resize` for textures (needs `sharp`, installed with it), `merge`, `inspect`.
- Python 3 standard library only, for download helpers (`Art/scripts/fetch_itch.py`, `fetch_ambientcg.py`) and a glb inspector (`glb_info.py`). Run as `python -I Art/scripts/<script>`.
- Blender: not installed on the owner's PC and not needed. Headless Blender would be considered only if a clip cannot be had otherwise (default: not needed). Accessories (hood, harness, helmet, vest, radio, trims) are generated by scripts from boxes and cylinders in glTF (gltf-transform API) and merged into the character files.
- Git Bash note: node cannot read `/c/...` paths. Use `C:/...` paths when passing files to `npx gltf-transform` from Git Bash.
- Every processed file must be rebuildable from `Art/sources/` plus the URLs below by a script in `Art/scripts/`. `build_character.sh` already holds the reduction recipe with measured numbers; each later issue adds its own build script.

## Sky and night
Procedural gradient sky and stars in client code (no texture), plus optionally one tiny prefiltered environment texture (`tex_env_night`, from Poly Haven kloppenheim_02_puresky, about 120 KB after processing) for faint reflections. No full HDRI ships.

## Gaps for gap-fillers
Server rack, fence and ladder strip have no direct CC0 model chosen. Plan: server rack = `mesh_prop_locker` or `mesh_prop_shelves` plus script-made emissive LED strips; fence = `Prop_Rail_*`/`Platform_Rails_4`; ladder strip = `Prop_Rail_4` plus script-made rungs. If these look wrong, check Kenney (CC0, see `Art/licenses/kenney.txt`, re-verify each pack's page) before building from boxes.

## Layout
- `Art/scripts/`: repeatable commands. `Art/sources/`: small originals only. `Art/licenses/`: licence records. `Art/STYLE.md`: style guide.
- `client/public/assets/{characters,props,textures,effects}/`: processed, final files (empty until the asset issues).


## Characters (M8, #81) - built, not hand-made
Scripts: `Art/scripts/char_lib.mjs` (shared), `build_ghost.mjs`, `build_warden.mjs`, `build_rifle.mjs`, runner `build_characters.sh <UAL1 glb> <UAL2 glb> <Gun_Rifle.gltf> <T_Guns_Batch1_BaseColor.png>`. Sources are re-downloaded (see Originals), each archive extracted into its own fresh folder; the scripts only parse the files as data. `inspect_rig.mjs` prints a glb's skeleton and clips.
- **Both characters use the UAL mannequin** (realistic proportions, 23 joints after merging the finger joints into the hands). KayKit Mannequin_Medium was rejected: cartoon proportions (head half the body height), a smiley face and a printed "HELLO my name is" tag.
- One skinned primitive each, a 512 px flat-colour PNG palette atlas embedded in the glb (PNG instead of WebP so no loader extension is needed; 1.6 KB), no external files, 1.8 m tall, feet at y=0, facing +z at yaw 0 (verified in Babylon; the loader's root mirror keeps +z facing +z). The bind pose is a T-pose, so play a clip before showing the model.
- Ghost 3,600 tris, 349 KB: idle, walk, run, jump, fall, land, hit, crouch_idle, crouch_walk, mantle (UAL2 ClimbUp_1m, carries upward pelvis motion). **climb, hang, shimmy are not in the files** (procedural in client code, as planned).
- Warden 4,220 tris, 349 KB: idle, walk, run, jump, fall, land, hit, idle_rifle, walk_rifle, run_rifle, fire, reload. The rifle clips come from the UAL two-handed pistol poses (the left hand is near the grip, not the foregrip); walk_rifle and run_rifle are the locomotion legs with the held aim pose on the upper body.
- Rifle 1,393 tris, 77 KB: the source atlas has small printed serial text, so it is recoloured from the palette instead. Nodes `muzzle`, `grip`, `light_mount`. Attach recipe is in the manifest notes.
- Character category total about 0.78 MB (budget 1.5 MB).
